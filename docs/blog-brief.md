# ブログ用ネタ帳

Node.js 20.12以降が必要です。プロジェクトの `.env.local` に `NEXT_PUBLIC_SUPABASE_URL` と `SUPABASE_SERVICE_ROLE_KEY` を設定し、プロジェクト直下で実行します。

```powershell
npm.cmd run blog:brief
npm.cmd run blog:brief -- --days 30
```

既定は90日です。`runtime-data/blog-brief/` に日本時間の日付を使った `brief-YYYYMMDD.json` と `brief-YYYYMMDD.md` を作成します。同日の再実行では同名ファイルを上書きします。このフォルダは Git 管理対象外です。Supabase は読み取りのみで、外部 AI は呼び出しません。

SNSの件数・タグ・反応、トレンドリンク、キーワード、最新取り込みの Search Console・GA4、既存記事の題名など、ブログのテーマ検討に必要な項目と今月から3か月の季節情報を含めます。取得できないセクションは空にし、理由を記載します。

期間は実行時点から指定日数分です。SNSは投稿日、トレンドリンクは登録日で絞ります。日付のみの値は日本時間の期間開始日と終了日を含め、投稿日不明のSNS投稿は集計しません。既存記事とキーワードは全件、Search Console・GA4は最新の取り込み分を対象とします。既存記事は公開日（なければ作成日）の新しい順です。

SNSの反応上位は4指標の合計順で、平均は値のある投稿だけを対象とします。GA4はページごとに行の数値を合算するため、取り込みデータの集計軸が重複している場合、ユーザー数などを重複計上する可能性があります。

投稿本文・SNS投稿のタイトルや URL・アカウント名・ハンドル・生データ、トレンドリンクの URL・長文メモ、記事本文、GA4 のリンク先やリンク文字列、認証情報は含めません。自由記述には URL・メール・電話番号などを除く処理を行いますが、人名などすべての個人情報を機械的に判別することはできません。共有前に内容を確認してください。
