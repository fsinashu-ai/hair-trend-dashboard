## 3. 進め方の案

1. **B の転送（10本）と C・E の noindex**: まとめ先に移す内容があるかをトレンド・SEOが記事ごとに確かめ、移す文案を付けてホームページ部署へ渡す。ホームページ部署が、バックアップ → 追記 → 301 → サイトマップ確認の順で反映する。
2. **A の書き直し（まず 268 と 284）**: 週1本のブログ作成の流れ（[blog-workflow.md](blog-workflow.md)）に入れる。公開後にホームページ部署が登録をリクエストする。
3. 反映の2〜4週間後に、トレンド・SEOが Search Console で登録数と表示回数を確かめる（毎月7日の月次レポートに含める）。

- 元に戻す方法: 301 は転送の設定を消して記事を公開に戻す。noindex は設定を外す。作業前にホームページ部署のバックアップ（JetBackup）を取る。
- 2017〜2018年の記事の多くは 2026-10-17 に一括で更新されている。268 と 284 が10月に検索から外れた時期と近いため、その日に何を変えたかをホームページ部署に確かめる。

## 4. 任意の技術項目（優先度低、ホームページ部署）

- WP Statistics の計測用 URL（`admin-ajax.php?action=wp_statistics_custom_event…`）が Google に20件拾われている。害はないが、気になる場合は robots.txt でこの URL だけ巡回を止められる。
- フィード（`/feed/`、タグのフィード）が未登録なのは正常。対応不要。
